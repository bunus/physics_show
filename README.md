# 高中物理动态演示 · Physics Showit

一套按人教版（2019）教材顺序组织的高中物理动态教学网页：6 册、27 章、135 个交互情境，面向四川成都高中物理课堂。
每章一个可独立打开的单文件页面，用「左栏情境 + 中栏画布 + 右栏要点 + 底部图鉴」的结构，把物理过程、公式与实时数据联动起来。

打开根目录的 [index.html](index.html) 进入总览，选择章节；也可以直接双击任意章节目录下的 index.html。

> 无需联网、无需安装依赖、无需本地服务器。现代浏览器（Chrome / Edge / Firefox / Safari）直接打开即可。

![高中物理动态演示总览](preview.png)

## 快速开始

1. 双击根目录 index.html，按教材分册浏览 27 章。
2. 点击缩略图或「快速预览」在本页内嵌查看演示；「打开页面」在新窗口打开。
3. 在章节页左栏切换情境，拖动画布端点或调节滑块、开关。
4. 顶部「重置本节」恢复当前情境，「全屏」用于课堂投屏；带播放键的情境可播放 / 暂停物理过程。
5. 键盘 ← / → 切换情境，空格播放或暂停。

### 课堂使用建议

- **新授课**：先用第一个情境建立直观，再切到规律与公式情境，最后用应用情境收束。
- **复习课**：直接点底部「情境图鉴」跳转到目标情境，配合右栏实时数据讲解。
- **实验课**：用滑块改变条件，让学生先预测、再看数据是否与预测一致。
- **投屏**：进入全屏，隐藏浏览器地址栏；画布与数据会随窗口自适应。

## 目录结构

```
物理演示/
├─ index.html                总览页（由 _template/portal.py 生成）
├─ <章>/index.html           单文件章节页（构建产物）
├─ <章>/preview.png          章节预览图
├─ <章>/README.md            章节说明
└─ _template/                构建源
   ├─ template.html         布局 / 样式 / Canvas 引擎
   ├─ src/<章>/modules.js   本章 5 个情境
   ├─ src/<章>/meta.json    标题与文案
   ├─ build.py / portal.py / make_readmes.py / make_previews.py / qa.py
   └─ manifest.json         教材目录
```

---

## 构建与维护

```bash
python3 _template/qa.py            # 构建全部章节 + 运行时自检
python3 _template/make_readmes.py  # 生成各章 README
python3 _template/make_previews.py # 生成各章 preview.png（Windows Edge）
python3 _template/portal.py        # 生成根目录总览页
```

只改某一章时：

```bash
python3 _template/build.py 抛体运动
```

## 说明

- 单文件交付：HTML / CSS / JavaScript 与全部图形均内联，可单独复制到任意目录双击打开。
- 所有画面由 Canvas 实时绘制，无外部图片、字体或第三方库。
- 物理量取 g = 9.8 或 10 m/s² 时会在各章公式与读数中统一说明。
- 拖动端点被限制在当前视野内；刷新后回到第一个情境。
